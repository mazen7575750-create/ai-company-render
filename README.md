## 🔄 نظام التحديثات (مجاني للأبد)
- التطبيق يفحص `version.json` عند كل فتح (مع نت) ويُحدِّث نفسه تلقائيًا.
- زر **🔄** في الشريط العلوي يفحص التحديثات يدويًا ويقول لك إن وُجد إصدار أحدث.

### عند كل تعديل (خطوتان فقط)
1. عدّل `mohfaz.html` وارفعه على `main`.
2. حدّع الرقم نفسه في **المكانين**:
   - `mohfaz.html` → `const APP_VERSION = "2026.11.23.1"`
   - `version.json` → `"version": "2026.11.23.1"`

أرسل الملفين معًا دائمًا — وهذا كل شيء، الجهاز يتحدث لاحقًا عند الفتح.

## 📱 تطبيق APK
- **حمّل أحدث APK من:** https://github.com/mazen7575750-create/ai-company-render/releases

- تفاصيل البناء اليدوي والمشاكل المحتملة: **[APK.md](./APK.md)**
